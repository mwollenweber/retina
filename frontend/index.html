About this map

Retina is a self-hosted, community-collected map of surveillance cameras in New Orleans. The focus is Project NOLA, the private camera network that has fed live facial recognition alerts to police.

Sources: field reports from the public (each reviewed with photos before it appears), the City of New Orleans traffic camera dataset on data.nola.gov, and OpenStreetMap.

Each point is a best-effort placement. Use the Street View link in a popup to verify. Found a mistake? Use Report a camera and describe the correction.
